# 🏏 Cricket Quiz Game 🎯

This is a simple web-based **Cricket Quiz** application built using HTML, CSS, and JavaScript. It tests your knowledge of cricket with **5 randomly selected questions**, and awards marks based on your chosen answers. You get a score out of 5 at the end of the quiz.

---

## 🔧 Features

- 🧠 5 Random Cricket Questions per attempt
- ✅ Multiple choice answers
- 🏆 Score displayed at the end (out of 5)
- 🔁 Option to retake the quiz
